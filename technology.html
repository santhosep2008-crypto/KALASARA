KALASARA • SMART WATER PURIFICATION

Technology Behind KALASARA

An integrated purification and monitoring platform designed to transform contaminated water into a controlled, measurable treatment process.

Inside the KALASARA System

The KALASARA prototype combines water-treatment stages, sensing, control electronics and renewable power inside a compact architecture. The system is designed so that water moves through defined treatment stages while important quality parameters can be monitored digitally.

KALASARA Prototype — CAD Architecture and Internal Component Arrangement

Core Technology

Each module performs a defined function within the overall purification and monitoring architecture.

💧

Pre-Treatment

The incoming water is directed through an initial filtration stage to reduce larger suspended particles before subsequent treatment.

🧪

Treatment Chamber

A controlled chamber provides the space for the selected treatment process used in the KALASARA prototype.

🌀

KALASARA Membrane

The membrane stage provides a selective filtration barrier within the treatment pathway. Performance is validated through experimentation.

📡

Smart Monitoring

Sensors can measure pH, TDS, turbidity and temperature, with an ESP32 controller supporting digital data transmission.

Major System Components

Hardware modules integrated into the KALASARA prototype.

COMPONENT 01

Raw Water Inlet

Receives the contaminated water and directs it into the treatment system.

COMPONENT 02

Filter Assembly

Provides the initial physical filtration stage for suspended matter.

COMPONENT 03

Treatment Chamber

Houses the selected treatment process within a controlled volume.

COMPONENT 04

KALASARA Membrane

Provides the membrane-based separation stage of the prototype.

COMPONENT 05

Sensor Module

Supports measurement of selected water-quality parameters.

COMPONENT 06

ESP32 Controller

Collects sensor readings and supports wireless connectivity.

COMPONENT 07

Solar Power Unit

Provides a renewable power option for the prototype system.

COMPONENT 08

Clean Water Outlet

Delivers water after it passes through the defined treatment stages.

COMPONENT 09

Digital Dashboard

Displays measured water-quality data and system status.

Design Approach

KALASARA follows a modular architecture in which purification, sensing, control and power sections are integrated into one compact system. Treatment performance should be validated experimentally using actual water samples and measured sensor data.
